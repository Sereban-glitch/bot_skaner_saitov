# Бот графиков отключений света

Следит за каналом @Zaporizhzhyaoblenergo_news, публикует график в
@svobodnye_ludi_zp и присылает личные уведомления по очереди 1.2
настроенным получателям.

## Как работает

- Проверка источника каждые 2 минуты (systemd-таймер).
- В канале ведётся один пост на день: при обновлении графика бот
  редактирует его, а не публикует новый. На новый день создаётся новый
  пост, чтобы подписчики получили уведомление.
- В личку приходит новое сообщение (с пушем), предыдущее удаляется.
- В посте указывается время данных источника: «За даними обленерго на HH:MM».
- Ночью (23:00–07:00 по Киеву) сообщения не отправляются.
- Хеш графика учитывает дату и ревизию поста источника, поэтому одинаковые
  часы в разные дни не считаются «без изменений».

## Настройка получателей

Личные получатели задаются в `.env`:

```
POWER_RECIPIENTS=sergey:@username1,ksusha:@username2,miron:@username3
```

Ключи (`sergey`, `ksusha`, `miron`) должны совпадать с шаблонами сообщений
в коде. Список хранится только в `.env` и в git не попадает.

## Файлы

- `power_schedule.py` — сам бот.
- `power_schedule_state.json` — состояние (хеш, ID сообщений). Создаётся
  автоматически, в git не хранится.
- `power_schedule.log` — лог, ротация на 5 МБ (3 архива).
- `.env` — API_ID, API_HASH и POWER_RECIPIENTS (в git не хранится).
- `analytics.session` — Telegram-сессия (в git не хранится, это секрет).

## Установка с нуля

1. Скопировать `power_schedule.py` в рабочую папку.
2. Создать виртуальное окружение и поставить зависимости:
   `python3 -m venv .venv && .venv/bin/pip install telethon`
3. Создать `.env` по образцу `env.example`.
4. Авторизовать Telegram-сессию (при первом запуске Telethon попросит
   номер телефона и код) — появится `analytics.session`.
5. Скопировать юниты из этой папки в `/etc/systemd/system/`, выполнить
   `systemctl daemon-reload` и `systemctl enable --now power-schedule.timer`.
6. Проверить: `.venv/bin/python power_schedule.py --preview` (ничего не отправляет).

## Важно

`analytics.session` и `.env` не восстанавливаются из GitHub — это секреты.
После переезда на новую машину сессию нужно авторизовать заново.
